1. What the check is

Each Cabinet-Level entry rests on a list of evidence items: a short description and a link to the source it cites. The Evidence drawer on an entry shows that list. Next to each item it shows the result of an automated source check: software fetched the cited page and compared what the page says with the item's description. The check is a reading aid. It is not a ruling, and it does not replace reading the source. Entries also carry short dated recheck notes that record when TAP looked at the entry again. Most of these notes record that a recheck found nothing new. They are not the sources the entry rests on, so the drawer does not list them and its item count leaves them out.

2. What it does and does not do

  • It reads one page per item: the cited link, or an archived copy of that page when the live page could not be read.
  • It compares the description with that page's text, detail by detail (names, numbers, dates, actions, and any outlet or document the description names).
  • It does not search for other sources, does not use anything it already knew, and does not check facts that the cited page does not cover.
  • If an item names two outlets but cites one link, only the cited page was checked. Each item therefore states which site it was checked against.
  • Software produced the checks. A person has not read each one.

3. How to read each label

  • Source supports the main assertion. The page states the item's main point. A minor detail in the description may be missing from the page.
  • Source supports part of the claim. The page supports some of the description but at least one specific detail is missing or different. The reason is shown.
  • Claim not found on this page. The page was read but the description's key facts were not found on it. This does not mean the claim is false.
  • Couldn't open this source automatically. The page could not be read by software, for example because the site blocks automated readers, or because the page's text could not be read even though the page was fetched (a PDF the software could not turn into text, or a capture that held only the site's navigation). It also covers a page where only part could be read (for example a paywalled page that shows only a teaser, or text cut off before the relevant section), because the claim might sit in the part the software never saw. This says nothing about the claim. For these items the date shows when the check was attempted.
  • Source differs from the description. A person reviewed a check that found the page differs from the description. Such items are corrected in the entry where possible.
  • Not yet checked. The item was added or changed after the last round of checks.

4. How accurate it is

Before the checks were published, a blind spot-check was run: 118 checked items were drawn across the different results, and independent automated readers (separate AI runs that were not told the original result) fetched each cited page and judged it again. 89 of the 118 pages could be opened by the second readers. Among those 89:

  • The second readers never found an item rated "supports" to be unsupported by its page.
  • Of the items rated "supports", 27 of 38 (71%) matched on every detail. The others were missing a minor detail, for example a word in the description or a second outlet the description mentions.
  • Of the items rated "supports part of the claim", 34 of 35 (97%) were confirmed as partial.
  • Of the items rated "claim not found", 5 of 16 were confirmed. In the other 11, the second reader found the page did support the claim or part of it. A "claim not found" label is therefore weaker evidence than the other labels.

The sample was small, so these figures carry wide margins. Sources from two large sites that refuse automated readers were left out of the sample, and 25% of sampled pages could not be opened by the second readers. The figures may not hold for sources from those two sites.

5. Limits

  • The check reads one page per item and can miss a detail or misread one.
  • A "supports" label means the page supports the main assertion, not that every detail matches.
  • The checks are a snapshot. Entries are updated, and a check is shown only while the item's text and link still match what was checked.
  • Where a check or an entry is found to be wrong, the entry is corrected and the item is checked again.
  • The second reading was also automated, and the tool it used to fetch pages summarises long pages, so the accuracy figures describe agreement between two automated readers. They are not a human audit.

6. Keeping the checks current

Checks are refreshed in batches, by hand, after larger updates to the entries, so the timing varies. An item whose description or link changed after its check shows "Not yet checked" until the next refresh. The date next to each check shows when it was made.
